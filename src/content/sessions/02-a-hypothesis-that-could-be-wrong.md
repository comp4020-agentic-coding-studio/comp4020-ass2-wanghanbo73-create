## Before the session

Bring the observation log from Week 1's system-reading habit — this session
reuses it as the starting material for hypothesis formation, on a slightly
larger system.

## In the session

The system this week has a reproducible failure with two superficially
similar but distinguishable causes, both findable from the code alone. You
submit a hypothesis and the specific test that would disconfirm it *before*
you're allowed to run that test, then report what actually happened — a
guess that survives contact with its own disconfirming test is treated
differently from one that doesn't.

## Afterwards

Revising a hypothesis on genuine disconfirming evidence is graded as
successful investigation, not as having gotten it wrong the first time.
